# The snouted swimmers

The ten swimmers of the confirmation round's trickle pool, each with D235's short nose grafted on. They are for a round
whose cell table lists the nose (`EVOSIM_NOSE`). There no other part smells, and these let the round found or trickle in
grazers that smell from the start.

The ten sources are `inocula/r59-direction-tops`, which `runs/r62cf-<seed>`'s `pool/04.json` to `13.json` hold byte for
byte, so each is a body r62cf could have admitted. Each was grafted by the nursery's `--graft-nose` on branch `nose`
at `c9642647`. The config was `rounds/nursery/configs/11819c680236db49.json`, whose development and shape settings
equal r62cf's, and the options were `--anchor 0,0.6,-1 --axis 0,0,-1 --area 0.0288 --slenderness 1.5`. That gives a
6 by 6 by 9 cm snout on the root's front face, above the mouth, pointing the way the body swims, on a fixed joint.
Every smell link moved onto the snout. A leaf-scent direction link from a part whose frame is not the snout's is
spread over the snout's components. At rest, the brain then feels the leaf's direction as it did before the graft. The ten are equal,
genome for genome, to the pool `95dde562a645c1a3`, which `--graft-nose` makes from
`rounds/nursery/pools/410a70db44a4b20a.tsv` with config `ecbba999e231021c`. Nursery entry 25 swam and filmed an
earlier graft without that reframing, the pool `06c9b91ce9a3d835`, and these differ from it in every genome.

Each file is the grafted genome's JSON as the build wrote it, one line and a newline, named as its source is named.
`origins.tsv` gives each file's exam id and SHA-256.

`rounds/r62cf-nose-pool.tsv` is r62cf's own list (`rounds/r59-pool.tsv`) with the ten swimmers' paths pointed here and
the four stomachs kept, at the same weights. `rounds/env-r62cf-nose-snout.ps1` uses it, and
`rounds/env-r62cf-nose-floor.ps1` also founds the whole floor from it.
